Editor autogestionable

Reglas de uso, cancelacion y reembolso

Estas reglas aplican al acceso del panel para editar tu sitio web.

Precio por sitio

El editor se paga por cada sitio web. Si tienes dos sitios, cada uno requiere su propio periodo activo.

Duracion del acceso

El acceso dura el periodo pagado: 1, 3, 6 o 12 meses. Si vence, tu pagina sigue en linea, pero el editor queda pausado.

Que incluye

Puedes cambiar textos, imagenes, videos, horarios, precios, promociones y datos basicos del negocio cuando el editor este activo.

Que no incluye

No incluye redisenos completos, nuevas secciones especiales, sistemas a medida, cambios tecnicos avanzados ni soporte ilimitado. Esos trabajos se cotizan aparte.

Cancelacion

Puedes pedir que no se renueve o que se pause el acceso. Si ya pagaste un periodo, conservas acceso hasta que termine.

Reembolsos

No hay reembolso despues de activar el acceso, salvo cobro duplicado, error de cobro o una falla tecnica nuestra que impida usar el editor.

Soporte

Problemas de cobro, cancelacion, reembolso o activacion se atienden por WhatsApp para revisar cada caso.
