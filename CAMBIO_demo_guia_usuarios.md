# Guía para usuarios demo — Fase 1

- Se añadió una guía visual local para selector, panel, proyecto y Editor.
- La guía resalta elementos reales y explica un paso a la vez.
- Cada pantalla recuerda si ya se mostró; el botón flotante con birrete permite abrirla otra vez.
- Administrar tienda queda fuera de esta primera guía.
- No se conectan servicios reales ni se guardan datos fuera del navegador.

## Corrección de enfoque, navegación y bloqueo

- Se añadió Atrás y navegación con teclas izquierda/derecha.
- El foco usa una ventana transparente: el elemento señalado queda visible.
- El mensaje se separa automáticamente del elemento destacado.
- La página queda bloqueada hasta usar Omitir o Terminar.
- El editor señala su instrucción de edición y no el iframe completo.

## Guía dentro de herramientas

- El Editor conserva su guía visual de cinco pasos.
- Administrar tienda incorpora una guía propia: productos, creación, búsqueda, opiniones, configuración y regreso.
- La guía abre cada sección automáticamente y bloquea acciones hasta Omitir o Terminar.
- No presenta inventario, pedidos ni equipo.

## Guía contextual de Administrar tienda

- Resumen, Productos, Opiniones y Configuración tienen recorridos independientes.
- Cada recorrido se muestra una vez al abrir su apartado por primera vez.
- Abrir un producto inicia una guía adicional de precio, moneda, medios, visibilidad y guardado.
- El botón flotante reproduce solamente la guía del apartado visible.
- Se eliminó el recorrido lineal que cambiaba de secciones automáticamente.
